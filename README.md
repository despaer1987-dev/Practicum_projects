# Practicum_projects
**QA portfolio**.
Дипломная работа первой части курса "Инженер по тестированию от новичка до автоматизатора" в Яндекс Практикум. Тестирование веб приложения "Яндекс самокат"
Составлен чек-лист по требованиям к экрану «Статус заказа».Для экрана «Сделать заказ» составлены проверки на валидацию полей. Проведено тестирование всей функциональности не только по получившимся чек-листам и таблицам, но и по макетам и остальным требованиям
Спроектированы тест кейсы на верстку по макетам  и по ним протестировано мобильное приложение "Яндекс самокат" ,с применением android studio и devtools.
Разработан чеклист и протестировано API по установленным требованиям.
По всем разделам заведены багрепорты.
